# Parakeet Admin API

NestJS + PostgreSQL + TypeORM backend for the Interview Intelligence dashboard and the existing KS Vision desktop app.

## Scripts

- `npm run start:dev` — watch mode on port 3001
- `npm run migration:run` — apply TypeORM migrations
- `npm run seed` — demo org/user/session
- `npm test` — unit tests

See `../docs/ARCHITECTURE.md` for the Rust contract and ER overview.

Swagger: `/api/v1/docs`
